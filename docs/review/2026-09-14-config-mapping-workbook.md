## 3. SLA 业务日历（`business_hours` JSON）

### 3.1 结构模板（写入 7 条 seed SLA）

```json
{
  "work_days": [
    1,
    2,
    3,
    4,
    5
  ],
  "start_time": "08:30",
  "end_time": "17:30",
  "time_zone": "Asia/Shanghai",
  "holiday_list": [
    "<见 3.2>"
  ]
}
```

- `work_days` 1–5 = 周一至周五；`start_time`/`end_time` 为每日工作时段。
- **GAP**：旧侧 `08:30–12:00` + `13:00–17:30`（含午休），新解析器只支持单一连续时段，**无法表达午休**；本表暂用 `08:30–17:30`（含午休），待确认采用 `09:00–18:00` 或新增能力。
- **GAP**：解析器不消费 `time_zone`；周末补班日无法表达（`work_days` 为固定星期）。补班需在截止计算验证中显式处置，不能仅写 JSON。
