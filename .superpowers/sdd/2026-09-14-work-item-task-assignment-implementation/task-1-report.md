# Task 1 report: explicit BPMN assignment source

Status: source-only intermediate implementation. It has not been deployed, and no shared database migration was run.

## Scope implemented

- Added the exact `work_item_assignee` BPMN user-task source and namespace-compatible XML attribute.
- Added fail-closed source validation for unsupported values, non-fulfillment tasks, participant selectors, approval selectors, and delegated handlers.
- Applied validation during publication and immediately before runtime task creation.
- Persisted the immutable source on `ProcessTask`; bound tasks bypass requester/trigger/assignee-variable fallbacks and persist empty assignee/candidate fields.
- Added migration 032, its operational SQL, and verification SQL. The database constraints allow only empty or `work_item_assignee` and reject bound rows with persisted assignee/candidates.
- Generated Ent code with `go generate ./ent`; generated changes add `assignee_source`, its default, builders/predicates/mutation support, and expected field-index shifts. No unrelated schema was introduced.
- Updated the 030/031 migration registry tests to assert the explicit 030 -> 031 -> 032 sequence rather than fixed positions relative to the end of the registry.
